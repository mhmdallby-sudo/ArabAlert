# ArabAlert 🚨

نظام تنبيهات احترافي للبث المباشر على تيك توك

## المميزات ✨

- ✅ إضافة تنبيهات مخصصة
- ✅ إدارة الألوان والخطوط
- ✅ رسوم متحركة للتبرعات
- ✅ صور وفيديوهات متحركة
- ✅ معاينة مباشرة
- ✅ واجهة احترافية وسهلة الاستخدام

## البدء السريع 🚀

### المتطلبات
- Node.js 14+
- npm أو yarn

### التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/mhmdallby-sudo/ArabAlert.git
cd ArabAlert

# تثبيت المتعلقات
npm install

# تشغيل التطبيق
npm start
```

سيفتح التطبيق تلقائياً على `http://localhost:3000`

## الاستخدام 📖

1. **لوحة التحكم** - تصفح المشروع واطّلع على المعلومات الأساسية
2. **إعدادات التنبيهات** - خصص رسائل التنبيه والمدة والرسم المتحرك
3. **إدارة الألوان** - اختر الألوان المناسبة لتصميمك
4. **إدارة الخطوط** - اختر الخطوط وأحجامها
5. **رسوم التبرعات** - أضف تأثيرات بصرية للتبرعات
6. **المعاينة** - شاهد تنبيهاتك قبل الاستخدام
